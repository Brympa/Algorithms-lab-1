# Лабораторная работа №1: Эмпирический анализ временной сложности алгоритмов

Автоматизированный комплекс для эмпирического исследования временной сложности алгоритмов, аппроксимации методом наименьших квадратов (МНК), оценки среднеквадратичной ошибки (MSE) и интерактивной визуализации результатов.

Разработано в рамках дисциплины «Алгоритмы и структуры данных» по техническому заданию лабораторной работы №1.

---

## 🛠 Стек технологий

* **Платформа:** .NET 10.0 (C# 14)
* **Клиентский GUI:** Blazor WebAssembly SPA (исполняется в браузере)
* **Серверный бэкенд:** ASP.NET Core Web API (Kestrel, Server-Sent Events стриминг)
* **База данных:** PostgreSQL 18 (Alpine, разворачивается через Docker Compose)
* **ORM:** Entity Framework Core 10, Npgsql
* **Графика:**
  * **Chart.js 4.4** — 2D графики замеров, кривые МНК, маркеры выбросов, мультисерийное сравнение.
  * **Plotly.js 2.35** — интерактивная 3D Surface визуализация времени умножения прямоугольных матриц.

---

## ⚡ Быстрый старт (Гайд по запуску)

### Требования
* [.NET 10.0 SDK](https://dotnet.microsoft.com/)
* [Docker Desktop](https://www.docker.com/products/docker-desktop/) (для запуска PostgreSQL)
* Современный веб-браузер с поддержкой WebAssembly

---

### Шаг 1. Запуск базы данных в Docker

В корне проекта выполните:

```powershell
docker compose up -d
```

> Контейнер PostgreSQL поднимется на порту `5432` с параметрами по умолчанию (`algolab` / `postgres` / `postgres`). Инициализация таблиц происходит автоматически скриптом `init.sql`.

---

### Шаг 2. Запуск бэкенда (Серверный API)

В первом окне терминала выполните:

```powershell
dotnet run --project AlgorithmLab.Server --no-restore
```

Сервер запустится на адресе: `http://localhost:5000`  
Документация Swagger UI доступна по адресу: `http://localhost:5000/swagger`

---

### Шаг 3. Запуск клиентского интерфейса (Blazor GUI)

Во втором окне терминала выполните:

```powershell
dotnet run --project AlgorithmLab.csproj --no-restore
```

После старта перейдите в браузере по адресу, указанному в консоли (обычно `http://localhost:5001` или `http://localhost:5288`).

---

### Шаг 4. Проверка подключения к БД из интерфейса

1. В боковом меню приложения перейдите во вкладку **«Конфигурация»**.
2. Нажмите кнопку **«Тест подключения»** (должен загореться зеленый индикатор успеха).
3. Нажмите кнопку **«Применить и подключиться»**.
4. Всё готово к проведению бенчмарков!

> [!NOTE]
> Приложение обладает **гибридным отказоустойчивым хранилищем**: если база данных PostgreSQL выключена, все замеры и кэш автоматически сохраняются локально в `localStorage` браузера в режиме офлайн.

## 🧪 Запуск автоматических тестов

Для проверки корректности алгоритмов, математического модуля МНК и детектора выбросов выполните:

```powershell
dotnet test AlgorithmLab.Tests/AlgorithmLab.Tests.csproj --no-restore
```

*(Все 16 юнит-тестов должны завершиться со статусом Passed).*

---

## 📦 Сборка автономного SPA-дистрибутива

Для публикации статического билда Blazor WebAssembly:

```powershell
dotnet publish AlgorithmLab.csproj -c Release -o publish --no-restore
```

Готовые статические файлы будут находиться в каталоге:
```
publish/wwwroot/
```

Их можно раздавать любым веб-сервером (Nginx, GitHub Pages, Caddy или `python -m http.server 8080 --directory publish/wwwroot`).

## 🧭 Навигация по приложению

| Вкладка | Назначение |
|---|---|
| **Бенчмарк сложности** | Основной экран: выбор алгоритма, настройка диапазона $N$, шага, числа прогонов. Живой SSE-график с кривой МНК и маркерами выбросов. Поддержка очереди задач. |
| **3D Матрицы** | Исследование умножения прямоугольных матриц $A(n \times m) \times B(m \times n)$. Интерактивная 3D-поверхность Plotly. |
| **Степени (Шаги)** | Исследование алгоритмов возведения в степень (Часть IV ТЗ): подсчет точного числа элементарных операций (умножений и рекурсивных вызовов) при $n \in [1, 1000]$. |
| **Сравнение из истории** | Сопоставление нескольких завершенных экспериментов на одном графике с общими осями. |
| **Визуализатор** | Пошаговая анимация работы алгоритмов сортировки с подсветкой сравнений, перестановок и разворотов. |
| **Конфигурация** | Настройки подключения к PostgreSQL и параметры Master Dataset (seed, распределение, экспонента). |
